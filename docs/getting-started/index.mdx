# Getting Started

The NetworkCore hub abstracts a clearing + settlement platform that ships
EV charging as its first vertical. This section covers the **platform-level**
concepts that apply regardless of which vertical you integrate with — parties,
sessions, clearing, webhooks, errors, idempotency, and authentication.

Once you're comfortable with the basics, jump into the [EV Charging](/ev-charging)
section for the role-specific integration guides.

## In this section

- [Core concepts](/getting-started/concepts) — parties, sessions, clearing, settlement
- [Authentication](/getting-started/auth) — OCPI tokens, partner JWT, admin keys
- [Sandbox](/getting-started/sandbox) — test credentials + the demo seed
- [Error responses](/getting-started/errors) — uniform error shape across the API
- [Rate limits](/getting-started/rate-limits) — per-tier limits + headers
- [Idempotency](/getting-started/idempotency) — safe retries for write operations
- [Pagination](/getting-started/pagination) — `limit` + `offset` conventions
- [Versioning](/getting-started/versioning) — how we evolve the API without breaking you
