# Pagination

List endpoints accept `?limit=` (default 50, max varies per endpoint) and
`?offset=` (default 0). Responses include a `total` field where computing it
isn't prohibitive.

For OCPI list endpoints, the standard `Link:` header with `next` / `prev` rels
applies per OCPI 2.2.1 §4.4.
