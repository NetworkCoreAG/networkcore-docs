# Sandbox

The sandbox runs the **same code** as production with `MOCK_INTEGRATIONS=true`.
All external integrations return canned responses — real session data
shapes, real CDR mechanics, no real money moves.

See the [full Sandbox page](/sandbox) for credentials + Postman collection.

## Test data

The sandbox has a built-in **demo seed** that populates:

- 5 demo parties (2 CPOs, 2 DPs, 1 dual-role DriverGo profile)
- 12 demo locations across Mexican cities
- 150 demo sessions with mixed statuses
- Cleared CDRs, settlements, invoices
- Sample chargebacks across every lifecycle state
- Risk fingerprints, fraud flags, BIN intelligence

Reset / re-seed via the admin demo endpoints — requires admin auth, your
NetworkCore ops contact can trigger it.
