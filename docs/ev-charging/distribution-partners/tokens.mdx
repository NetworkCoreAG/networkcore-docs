# Driver tokens

Once your driver authenticates in the eMSP app, push their OCPI token to the
hub so connected CPOs see them as authorised. The hub stores the token,
propagates it to CPOs, and auto-creates a driver profile for clearing.

## Push a token

```http
PUT /ocpi/2.2.1/emsp/tokens/MX/EMP/5b1f8e1f-c0e3-4a8b-95a8-2d5f8e9c1aaa
Authorization: Token TOKEN_C
X-Request-ID: ad81b7c3-6e72-4b4f-bf80-4b9d2f5d6d73
X-Correlation-ID: ad81b7c3-6e72-4b4f-bf80-4b9d2f5d6d73
Content-Type: application/json
```

```json
{
  "country_code": "MX",
  "party_id":     "EMP",
  "uid":          "5b1f8e1f-c0e3-4a8b-95a8-2d5f8e9c1aaa",
  "type":         "APP_USER",
  "contract_id":  "MX-EMP-CONTRACT-12345",
  "issuer":       "Example DP",
  "valid":        true,
  "whitelist":    "ALWAYS",
  "last_updated": "2026-04-29T10:00:00Z"
}
```

**Response** — `HTTP 200`:

```json
{ "status_code": 1000, "data": null, "timestamp": "2026-04-29T10:00:01Z" }
```

## Revoke a token

To revoke (driver loses their phone, account suspended, etc.), send the same
PUT with `"valid": false`, or PATCH the same URL with just the fields that
changed. The hub propagates the change to all connected CPOs within seconds.

```http
PATCH /ocpi/2.2.1/emsp/tokens/MX/EMP/5b1f8e1f-c0e3-4a8b-95a8-2d5f8e9c1aaa
Content-Type: application/json

{ "valid": false, "last_updated": "2026-04-29T18:30:00Z" }
```

## Token types

| `type` | Use case |
|---|---|
| `APP_USER` | Driver authenticates via your mobile/web app (most common) |
| `AD_HOC_USER` | One-off payment at the charger UI |
| `RFID` | Physical RFID card |
| `OTHER` | Non-standard methods (flagged for review) |

## Whitelist values

| `whitelist` | Meaning |
|---|---|
| `ALWAYS` | CPO can authorise locally without asking the hub (lowest latency) |
| `ALLOWED` | CPO can authorise locally OR ask the hub — implementation choice |
| `ALLOWED_OFFLINE` | CPO can authorise locally only if the hub is unreachable |
| `NEVER` | CPO must always ask the hub before authorising |

`ALWAYS` is the sensible default for drivers in good standing.
