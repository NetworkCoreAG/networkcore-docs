# Locations

On first integration, do a full pull so your in-app map shows every charging
station. After that, use `updated_since` on subsequent calls to fetch only
changed locations.

## List locations

```http
GET /dp/v1/locations?limit=100&offset=0
Authorization: Bearer <your_dp_api_key>
X-Request-ID: bf92c8d4-7f83-4c5e-c091-5c0e3f6e7e84
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `limit` | integer | 50 | Page size (max 1000) |
| `offset` | integer | 0 | Number of records to skip |
| `updated_since` | ISO 8601 | — | Only locations updated after this timestamp |
| `country` | string | — | Filter by country (ISO 3166-1 alpha-2, e.g. `MX`) |

**Response** — `HTTP 200`:

## Get a single location

```http
GET /dp/v1/locations/LOC001
Authorization: Bearer <your_dp_api_key>
X-Request-ID: c1a4b2d5-9184-4e7f-b2c3-7d2e5a81a0ab
```

## Sync strategy

1. **Initial full sync** — paginate through all locations with no `updated_since` filter
2. **Incremental updates** — run every 5–15 minutes with `updated_since` set to your last sync timestamp
3. **Weekly safety net** — do a full pull (no `updated_since`) once a week to catch any missed updates

Store the `last_updated` timestamp from each sync run so your next incremental
call picks up from where you left off.

## Location schema

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique location identifier |
| `name` | string | Human-readable station name |
| `address` | string | Street address |
| `city` | string | City |
| `postal_code` | string | Postal / ZIP code |
| `country` | string | ISO 3166-1 alpha-2 country code |
| `coordinates` | object | `{ latitude, longitude }` (decimal degrees) |
| `operator_name` | string | Name of the CPO operating this location |
| `open_hours` | string &#124; null | Opening hours description; `null` means 24/7 |
| `last_updated` | ISO 8601 | When the location was last modified |
| `charge_points` | array | List of charge points at this location |

## Charge point schema

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique charge point identifier within the location |
| `status` | string | `AVAILABLE` &#124; `OCCUPIED` &#124; `OUT_OF_SERVICE` &#124; `UNKNOWN` |
| `connectors` | array | List of connectors on this charge point |

## Connector schema

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique connector identifier within the charge point |
| `standard` | string | `CCS2` &#124; `CHADEMO` &#124; `TYPE_2` &#124; `J1772` &#124; `TESLA_S` &#124; `NACS` |
| `power_kw` | number | Maximum power output in kilowatts |
| `format` | string | `CABLE` &#124; `SOCKET` |
| `tariff_id` | string | Tariff that applies to this connector; use to fetch pricing via [`/dp/v1/tariffs/{id}`](/ev-charging/distribution-partners/tariffs) |
