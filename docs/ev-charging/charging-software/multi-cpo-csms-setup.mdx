# Multi-CPO / CSMS setup

CSMS partners (Ampeco, Driivz, Monta, ChargePoint, EVgo OS, Greenflux, Etrel)
typically host multiple CPOs under a single platform. Each underlying CPO gets
its own `(country_code, party_id)` and its own OCPI handshake — but you manage
all of them through the same NetworkCore relationship.
