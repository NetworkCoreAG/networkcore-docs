# EV Charging

EV charging is NetworkCore's flagship vertical. The hub implements OCPI 2.2.1
as both the CPO and eMSP sides, plus the financial layer (clearing, settlement,
risk, chargebacks) the OCPI spec leaves out.

## Pick your role

- [**For CPOs & CSMS**](/ev-charging/charging-software) — you operate the
  chargers. Push locations, sessions, CDRs, tariffs to the hub.
- [**For Distribution Partners**](/ev-charging/distribution-partners) — you
  bring drivers. Browse the location catalogue, start and manage charging sessions.
- [**For Accounting**](/ev-charging/accounting) — you handle the books.
  Pull invoices, settlement reports, reconciliation feeds.

If you also need driver-experience flows (history, push notifications, invoice
viewing), see the embedded driver API under the Distribution Partners section.
