# For Accounting & Finance

Finance integrations are read-mostly: pull invoices, settlement remittance
reports, reconciliation feeds. The hub exposes these via the partner portal's
`/portal/v1/cpo/*` and `/portal/v1/dp/*` endpoints (using a partner JWT) and via
the admin reports surface (using an admin token, for finance teams that own
multiple parties).
